# Upgrade to devrouter 0.6.3

This patch qualifies explicit fresh managed initialization on Devsy 1.24.0 in
addition to 1.19.0. The operation and its data, context and ownership guarantees
are unchanged. Ordinary startup retains its existing provider support.

## Task

Within an authorized consumer adaptation, install the published CLI, verify its
executable/version, bump `devrouter.version` in `.devrouter.yml`, and refresh
existing guidance with `devrouter repo agents`. Explicitly managed controllers
must use the matching initialization protocol. No configuration migration is
required for ordinary startup.

For a new disposable checkout, follow the current `docs/DEVCONTAINER.md`
`freshBootstrap` contract and request `ensure <path> --initialize-new` only
within existing consumer authority. Qualify the complete selected composition,
new local data volumes, explicit shared caches and repository-owned database
identity/emptiness checks. Unqualified provider versions and contexts refuse.

The durable attempt is consumed before provider creation. Failure, cancellation,
unknown completion, stop, replacement, registration loss and settlement never
rearm it. Preserve partial data and use supported preserving recovery. Never
clear the attempt or treat this operation as an existing-environment reset.

## Validation

1. Run the consumer's static configuration and bootstrap checks for actual edits.
2. With runtime authority, initialize a new disposable fixture on the exact
   qualified provider version; verify actual work, retained synthetic data
   through preserving stop/resume, and refusal of a repeated initialization.
3. Check failure/cancellation retention and replay refusal. End with canonical
   `devrouter stop <path>` and verify stopped provider state and zero exact routes
   unless the user explicitly retains the environment.

## Report

Report exact source/package/executable and provider identities, actual checks,
retained-data evidence, remaining consumer prerequisites and final runtime state.
A compatible release or installation alone does not prove consumer recovery.
