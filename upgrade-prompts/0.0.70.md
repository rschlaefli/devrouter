# Upgrade to devrouter 0.0.70

This patch release fixes host-port claim reporting so a holder that binds the
same port on both address families (0.0.0.0 and ::) is reported as one
conflict instead of duplicates. No schema, configuration, or CLI flag changes.

## Task

Install the published release and update `.devrouter.yml` devrouter.version to
0.0.70. No configuration change is required.

## Validation

On a repository whose managed overlay declares a fixed published binding that
a running container holds, run `devrouter doctor --repo <path> --json` and
confirm `repo.host-port-claims` reports one conflict per distinct binding, not
one row per address family. `devrouter ensure <path> --json` must return the
same single `hostPortConflicts` entry.

## Report

Report the tested CLI version, the repository and binding exercised, the
doctor check details, and whether duplicate conflict rows were observed.
