# Upgrade to devrouter 0.5.2

This patch release keeps the idle-stop agent's `sweep.log` readable.
`workspace idle --stop` no longer writes a lifecycle progress line every ten
seconds of each stop when its stderr is not a terminal, as under launchd, so
the log records only stop outcomes and errors. An interactive sweep still shows
progress. There is no configuration change and no migration.

## Task

Install the published 0.5.2 CLI. No repository change is needed. Bump a
repository's `devrouter.version` to 0.5.2 only when consumer source changes are
authorized. A machine that uses the idle-stop agent needs no setup rerun when
devrouter is installed through Volta, because the agent's entry path does not
change between versions.

## Validation

1. Run `devrouter -V` from the consumer checkout.
2. Run `devrouter workspace idle --json` and confirm it completes.

## Report

Report the release revision and the resolved executable with its installed
version.
