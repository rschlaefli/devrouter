# Upgrade to devrouter 0.5.5

This patch release fixes TCP-only and empty host-route generations. Devrouter
omits empty HTTP router/service maps so Traefik can load the file provider.
Existing v1 route metadata remains readable; the next route write or refresh
emits the corrected document. Other metadata/YAML mismatches still fail closed.
It also updates Dockerode to 5 to remove the UUID 10 dependency affected by
CVE-2026-41907. The existing Node >=24 requirement remains unchanged. There is
no configuration schema migration.

## Task

Install the published 0.5.5 CLI. Replace any temporary local patch for the
TCP-only rendering fix in PR #148 with the published package. Bump a consumer's
`devrouter.version` only when consumer source changes are authorized. No
generated configuration or agent artifacts require changes. Preserve existing
runtime ownership, containers, databases and dependency volumes.

## Validation

1. Run `devrouter -V` from the consumer checkout and confirm 0.5.5.
2. Run `devrouter doctor --json` and inspect runtime ownership and readiness.
   Verify a fresh installation resolves Dockerode 5 without UUID 10.
3. If the repository defines a TCP-only profile, run `devrouter ensure .` with
   that profile. Verify route publication succeeds and the expected TCP router
   is loaded. Test a client connection with the required TLS/SNI settings; for
   PostgreSQL direct TLS, retain ALPN `postgresql`.
4. Restore the intended application profile and run an existing application
   smoke test. Confirm the same app container and volumes are retained. Do not
   replay destructive bootstrap hooks or bypass lifecycle ownership checks.

## Report

Report the installed version, selected runtime and profiles, TCP/client and
application results, container/volume retention, and remaining limitations.
