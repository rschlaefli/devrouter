# Upgrade to devrouter 0.0.73

This patch release fixes output from capacity-enrolled `exec`. When an enrolled
checkout ran through the controller, the wrapped command's stdout and stderr
were captured into the controller's bounded output buffer and then discarded, so
`devrouter exec <path> -- <command>` returned only the exit status. The
controller-supervised path now streams that output to the caller and prints one
notice if the buffer dropped earlier bytes. No schema, configuration, or CLI
flag changes.

## Task

Install the published release and update `.devrouter.yml` devrouter.version to
0.0.73. No configuration change is required.

## Validation

On a capacity-enrolled checkout, run
`devrouter exec <path> -- bash -lc 'echo checked'` and confirm the command's
output appears. Confirm a failing command still returns its non-zero exit
status, and that `devrouter ensure <path>` reports the environment ready with
its routes published.

## Report

Report the installed CLI version, the enrolled repository, the observed `exec`
output and exit code, and the final `ensure` readiness with its route count.
