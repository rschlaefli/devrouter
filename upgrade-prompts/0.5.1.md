# Upgrade to devrouter 0.5.1

This patch release fixes lifecycle commands that failed with
`docker inspect failed: error: no such object: <id>` when any container on the
machine was removed while devrouter was listing containers, for example while
another checkout's stack was being recreated. `ensure`, `exec`, `stop`,
`status` and `workspace idle` now treat such a vanished container as absent.
Other inspect errors still fail. There is no configuration change and no
migration.

## Task

Install the published 0.5.1 CLI. No repository change is needed. Bump a
repository's `devrouter.version` to 0.5.1 only when consumer source changes are
authorized. A machine that uses the idle-stop agent needs no setup rerun when
devrouter is installed through Volta, because the agent's entry path does not
change between versions.

## Validation

1. Run `devrouter -V` from the consumer checkout.
2. Run `devrouter workspace idle --json` and confirm it completes.

## Report

Report the release revision and the resolved executable with its installed
version.
