# Upgrade to devrouter 0.5.4

This patch release fixes false Compose identity drift when provider-generated
entrypoints or configuration values contain literal dollar signs. Devrouter
undoes Compose serialization escaping before hashing the resolved configuration,
without another interpolation pass. There is no configuration schema migration.

## Task

Install the published 0.5.4 CLI. Remove any temporary local patch for the Compose
dollar-escaping fix in PR #146 by replacing it with the published package.
Bump a consumer's `devrouter.version` only when consumer source changes are
authorized. No generated configuration or agent artifacts require changes.
Preserve existing runtime ownership, containers, databases and dependency volumes.

## Validation

1. Run `devrouter -V` from the consumer checkout and confirm 0.5.4.
2. Run `devrouter doctor --json` and inspect runtime ownership and readiness.
3. Run `devrouter ensure .` with the intended profile and verify that an existing
   app container is retained without a false Compose drift failure.
4. Run an existing application smoke test. If stop/resume is tested, confirm
   the same container and volumes are retained. Do not replay destructive
   bootstrap hooks or bypass lifecycle ownership checks to test an upgrade.

## Report

Report the installed version, selected runtime, tested profile, container
retention and functional results, and any remaining limitations.
