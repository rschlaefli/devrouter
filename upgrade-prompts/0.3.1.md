# Upgrade to devrouter 0.3.1

This patch release makes the `workspace leftover` output readable. Each stack's
table row now shows per-kind counts, for example `removed 7 container(s), 42
volume(s), 1 network(s)`, instead of every removed container ID and volume
name. After an apply, one line points to the per-stack receipts and `--json`,
which still list every object.

There is no configuration change, no migration and no change to which objects
are removed.

## Task

Install the published 0.3.1 CLI. No repository change is needed. A repository
that requires 0.3.0 keeps working with 0.3.1.

## Validation

1. Run `devrouter -V` from the consumer checkout. A repository Volta pin can
   change which install resolves.
2. Optionally run `devrouter workspace leftover --manifest <file> --sha256
   <hash>` as a dry run and confirm each stack shows one row of counts.

## Report

Report the release revision and the resolved executable with its installed
version.
