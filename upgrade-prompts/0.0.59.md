# Upgrade to devrouter 0.0.59

This patch lets short-lived preparation children finish naturally after the
foreground command exits successfully. The helper holds its lifecycle lock and
checks cancellation during a bounded two-second drain window. Persistent children
still prevent application startup and use existing owned-group cleanup.

## Task

Install the published patch and update `.devrouter.yml` devrouter.version to
0.0.59 through the consumer workflow. No schema or dependency migration is needed.
The next authorized ensure delivers the matching runtime helper automatically.
Keep preparation synchronous and avoid detached sessions or process groups.

## Validation

On an authorized exact checkout, verify preparation finishes and the intended
profile starts. Test application readiness independently from successful build
output. Preserve data, stop task-owned runtimes and verify stopped provider status
and zero exact routes. Do not start another task's runtime to repeat qualification.

## Limits

An isolated Linux fixture proves natural drainage of a short-lived child and
continued rejection of persistent children. The reported Turbo descendant has
not been identified, so this patch alone does not prove that consumer startup
succeeds. Warm mount reconciliation, capacity admission and complete OOM protection
remain outside this patch.

## Report

Report installed version, exact checkout/profile, preparation outcome, application
readiness and final runtime state. Include remaining blockers without treating
cached build success as successful environment startup.
