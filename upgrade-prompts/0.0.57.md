# Upgrade to devrouter 0.0.57

This patch restores managed ensure with comma-separated profiles. Lifecycle events,
current state and retained request history accept profile selections separately
from workspace and operation identifiers. Repository resolution still validates
configured profiles and combines their selected resources.

## Task

Install the published 0.0.57 patch and update `.devrouter.yml` devrouter.version to
0.0.57 through the consumer repository workflow. No schema or database migration
is required. Keep the intended profile selection; do not substitute full or delete
runtime state to avoid the earlier validator failure.

## Validation

Use repository profile resolution to check the intended combined selection. Run
managed ensure only on an authorized exact checkout, retaining its data and
bindings. Report the resulting application and runtime outcomes separately from
successful selection validation. Stop only runtimes owned by the validation task,
then verify their provider status and zero exact routes.

## Limits

This patch fixes pre-dispatch profile validation. It does not introduce a host-side
preparation hook, warm Compose drift reconciliation, capacity admission, a
controller, autonomous agent recovery or complete OOM protection.

## Report

Report installed/configured versions, exact profile selection, validation result
and any separately authorized runtime evidence. Identify retained runtime leases
without ending another task's runtime.
