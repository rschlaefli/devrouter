# Upgrade to devrouter 0.0.71

This patch release repairs controller admission for capacity-enrolled
checkouts. Two client defects shipped in 0.0.69 and 0.0.70: supervised
operations bound with an empty requirement list that the controller protocol
rejects, and the observation binding validated the wire envelope instead of
the observation result. Enrolled `ensure` and `exec` therefore failed before
reaching the controller. The controller also now reports the bounded cause of
a failed operation on stderr. No schema, configuration, or CLI flag changes.

## Task

Install the published release and update `.devrouter.yml` devrouter.version to
0.0.71. No configuration change is required.

## Validation

On a repository with an enabled capacity policy enrollment, run
`devrouter ensure <path> --json` and confirm startup is admitted, then run
`devrouter exec <path> -- echo ok` and confirm the admitted operation completes.
`devrouter stop <path>` must end with the runtime stopped and zero routes.

## Report

Report the installed CLI version, the enrolled repository, the ensure and exec
outcomes, and the final stopped status with the route count.
