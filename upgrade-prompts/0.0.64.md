# Upgrade to devrouter 0.0.64

This patch lets canonical ensure wait for healthy lifecycle work on the same
checkout and clarifies process-inspection permission failures.

## Task

Install the published patch and update `.devrouter.yml` devrouter.version to
0.0.64. No schema migration or runtime restart is required. Refresh distributed
agent guidance through the existing repository workflow.

## Validation

Confirm the installed version. On an authorized runtime, invoke ensure while a
bounded tooling command is active. Verify waiting, preserved tooling exit status
and successful ensure after completion when the lifecycle fence stays unchanged.
Verify the exact runtime stops with zero routes and retained data when finished.
A waiting exec refreshes runtime proof before admission; ensure establishes its
runtime inside the worker. Stop or another fence change cancels the waiting
invocation. Never replay an uncertain command.

## Limits

Waiting is bounded to thirty minutes, with no FIFO guarantee or persistent queue.
Permission diagnostics direct agents to a permitted host context; they do not
repair operating-system permissions or authorize lock removal. This patch does
not solve network exhaustion, activate capacity admission, or claim complete OOM
protection or autonomous agent recovery.

## Report

Report installed version, exact checkout/provider, command outcomes, retained
runtime/data evidence and final runtime/route state. Separate published source,
synthetic checks and live consumer acceptance.
